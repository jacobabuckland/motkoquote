# PNL-4 — Voice "What's left?" must name what came off

Issue: #403

## Problem

The voice ledger query surface speaks the "what's left" figure aloud, and it is over-stated. `getWhatsLeft` currently returns `whatsLeft` from the money position, which is `collected − costsPaid` only—no VAT term and no fee term. For a VAT-registered trade the collected figure is gross, so the spoken number includes money that belongs to HMRC. The sentence correctly describes what happened ("after paying your costs"), which is what makes the over-statement convincing.

A spoken figure arrives alone, with nothing on screen to check it against, and it is gone once spoken. A false all-clear spoken aloud gets no second look.

## Scope

This ticket changes the voice "what's left" answer to use PNL-1's safe-to-spend figure and speak what was deducted, with amounts, in the same breath.

### Changes

1. **Type definition:** Define `WhatsLeftAnswer` in `src/app/ledger/query-actions.ts`:
   ```typescript
   export type WhatsLeftAnswer = {
     total: number;              // pence — safeToSpend.total from PNL-1
     costsPaid: number;          // pence
     motkoFees: number;          // pence
     vatToSetAside: number | null;  // pence; null when not VAT-registered
   };
   ```

2. **Server action:** `getWhatsLeft` in `src/app/ledger/query-actions.ts` returns `WhatsLeftAnswer` instead of a bare number, extracting the breakdown from `getMoneyPosition`'s `safeToSpend`.

3. **Formatter:** Create `formatWhatsLeftResponse` in `src/lib/voice/ledger-query-prompt.ts` (exported, beside `formatOwedToYouResponse`) that composes the spoken sentence. Shape:
   ```
   "You've got £99.20 safe to spend — that's after your costs, motko's fees, and £19.84 set aside for VAT."
   ```
   
   Rules:
   - Name the **amount** of each non-zero deduction (not just its existence)
   - Omit zero terms entirely
   - Never mention VAT if not registered (`vatToSetAside === null`)
   - For negative total: speak as a shortfall (e.g., "You're down £50.00...")
   - For exactly zero: "You've got nothing left to spend" (not "£0.00")
   - Use existing `formatAmount` for all figures

4. **Voice page:** Update `src/app/ledger/query/page.tsx` line 179 to call `formatWhatsLeftResponse(data)` instead of composing the sentence inline.

5. **Prompt strings:** Update two strings in `src/lib/voice/ledger-query-prompt.ts`:
   - Line 90 (tool description): from "Get what's left: money collected minus costs paid." to "Get safe-to-spend: money left after costs, motko's fees, and VAT (if registered)."
   - Line 156 (supported query list): from "5. What's left? — collected minus paid costs" to "5. What's left? — safe to spend after all deductions"

6. **Superseded tests:** Update three tests in `tests/acceptance/257.test.ts` (in the spec commit, under the 24 Aug precedent) that pin the old behaviour:
   - "calls getMoneyPosition from LED-4 and returns whatsLeft figure" (line 294)
   - "handles negative whatsLeft (spent more than collected)" (line 313)
   - "handles zero collected with costs paid" (line 627)
   
   Each mock must gain a `safeToSpend` object, and assertions change from `expect(result).toBe(N)` to `expect(result.total).toBe(N)`. Use the exact values from the table below—these are chosen so `whatsLeft ≠ total`, proving a regression to the old field cannot pass.

## Edge cases

- **Not VAT-registered:** `vatToSetAside === null` → no mention of VAT at all in the sentence
- **All deductions zero:** Collapse to bare total: "You've got £119.04 safe to spend."
- **Exactly zero total:** "You've got nothing left to spend" (not "£0.00 safe to spend")
- **Negative total:** Speak as shortfall, e.g., "You're down £50.00 — that's after your costs and motko's fees." (still names deductions)
- **Zero figure with negative spelling:** `formatAmount` on negatives already yields "minus ..."; compose around it rather than yielding a sentence that reads badly

## Risks

- **Money integrity:** The spoken figure and its breakdown must match what PNL-1 computed. Any arithmetic in the formatter is a defect—it receives values and formats them only.
- **VAT exposure:** A contractor who is not VAT-registered must never hear the word "VAT". This is criterion 3 and the assertion that matters most.
- **Frozen contract collision:** The three tests in `tests/acceptance/257.test.ts` are frozen by the immutability guard. They may only be updated in the spec commit (this one). An attempt to fix them later will block the item.

## Derived criteria

What I understood the human to be asking for:

1. The spoken figure changes from `whatsLeft` (collected − costs) to `safeToSpend.total` (collected − costs − fees − VAT)
2. The sentence names what was deducted, with amounts: "after your costs, motko's fees, and £19.84 set aside for VAT"
3. VAT is never mentioned if the contractor is not registered (`vatToSetAside === null`)
4. Zero deductions are omitted from the sentence (e.g., no costs → no mention of costs)
5. Each deduction's amount is spoken, not just its existence (criterion 2 says "name the amount")
6. Negative totals are spoken as shortfalls, not clamped to zero
7. The old sentence pattern ("after paying your costs") is gone
8. `getWhatsLeft` returns the PNL-1 total, verified by comparing the two calls
9. The two prompt strings at :90 and :156 describe the new behaviour
10. The three tests in 257.test.ts are updated in the spec commit with the exact mock values provided
